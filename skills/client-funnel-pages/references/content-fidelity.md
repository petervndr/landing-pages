# Content fidelity — real words, real numbers, right brand

Landing-page copy goes live in front of the client's prospects. Fabricated proof, a
leaked template placeholder, or the wrong brand word is worse than a visual bug — it's a
credibility (and sometimes legal) problem. These rules are non-negotiable; when in doubt,
leave it blank and ask rather than invent.

## Testimonials & proof — verbatim, never embellished

- Use the client's testimonial/review text **word-for-word** from the real source
  (transcript, review screenshot, doc). Light cleanup only (obvious filler, a stray
  "um"). **Never** polish, rewrite, "make it punchier," or improve the grammar.
- **Never attach a number the client didn't say.** No invented "$250k saved," "added
  $130k ARR," ratings, or client counts. If the source has no number, the testimonial has
  no number. (Real case: most of a client's testimonials had *no tax-savings figure* — so
  none was shown.)
- If you don't have the actual source text, **do not write a plausible quote.** Mark it
  `UNVERIFIED — need source` and ask Peter. Do not claim quotes are "word-for-word" or
  "transcribed" unless you actually pulled them from the source.
- Keep the client's real words even if they violate a brand-vocabulary rule below (a
  verbatim review that says "coaching" stays "coaching").

## Brand vocabulary & voice

- **SYAF: "advisory," never "coaching"** (advisory / advisory services). Applies to all
  SYAF-authored copy; the only exception is verbatim client testimonials.
- **No em dashes.** Run an em-dash sweep on every page; replace with commas/colons/periods.
- Scan copy against `copywriting/banned-phrases.md` and follow
  `copywriting/voice-principles.md`. Delete AI-writing tells (stacked one-word sentences,
  "it's not X, it's Y," stealth adverbs, "imagine if…", "let's dive in").
- **The prospect is the hero; the villain is external** (the old agency model, bad advice,
  the system) — never blame the prospect. See memory `feedback_prospect_is_hero`.

## Capitalization & polish

- The **live page must meet publish standards regardless of how the input was written.**
  If Peter (or a source doc) hands you lowercase or rough copy, apply proper
  capitalization and sentence casing. Never paste raw input verbatim onto a page.

## No template placeholder leakage

Before any page is called done, confirm **none** of the house-template's example content
survived the rebrand. Search the built pages for:

- The placeholder founder — **"hey I'm John" / "I'm John"** and any **"Profit First"**
  book reference. Replace with the actual client founder + real bio.
- Lorem/ipsum, "example," "REPLACE", "PLACEHOLDER", "TODO", "CALENDAR_ID", `#`-only hrefs.
- Placeholder / non-real statistics in stat blocks — use the client's **actual** numbers,
  and if you don't have them, ask; don't fill with round fakes.
- Example embed ids from the template (e.g. a shared/sample Wistia id) — every embed id
  must be the client's real one.

## Legal & compliance must match the real client

- The footer **earnings/results disclaimer must match the client's firm type.** An
  accounting / CFO / bookkeeping firm does not get a generic sales/marketing "results
  disclaimer." Adapt it (or drop it) to fit.
- **Compliance links (Privacy, Terms) must point to / match the client's real site**, and
  compliance links open in a **new tab**.
- Legal pages are boilerplate, not vetted advice — flag counsel review before publish
  (see SKILL.md).

## Bottom line

Every claim on the page is either **sourced from the client** or **not on the page.**
Every word is in the client's brand voice. Nothing from the template is left behind.
